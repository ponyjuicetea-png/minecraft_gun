# 驗證紀錄

日期：2026-10-17。Windows 64 位元；Luanti 5.17.0、VoxeLibre 0.92.3。

`scripts/test_integration.py` 已通過 **30 項**檢查。使用兩個真正連線的獨立 Luanti 客戶端與獨立測試世界，包含：

- 地圖產生及保護、出生裝備、備用彈藥。
- 射擊耗彈、射速限制、實心牆面遮擋。
- 遠距玩家傷害、頭部加成、PvP 關閉及出生保護。
- 換彈期間不可射擊、缺彈部分填裝、空彈匣與無備彈。
- 切槍／更換同種槍械取消換彈，沒有憑空增加彈藥。
- 瞄準 FOV、擊殺／死亡歸屬、自動重生、重新配發與回合重設。

`scripts/test_launcher.py` 驗證實際 PowerShell 啟動器可開啟背景伺服器、自動註冊／登入兩個本機玩家，以及透過停止腳本儲存並結束伺服器。

已檢視實際遊戲畫面；使用 NVIDIA OpenGL 4.6 渲染器，並確認寫實表面、陰影、HUD 與 3D 槍械可見。`preview.png` 是客戶端實際畫面，未經修圖。

Python 和 PowerShell 語法檢查通過。便攜 ZIP 已檢查 CRC／檔案完整性，並排除本機帳密、世界存檔、記錄與測試產物。

範圍限制：雙客戶端在同一台電腦測試；未測試不同實體電腦、跨住家路由器連線、長時間八人壓力或固定 FPS。射擊採伺服器當下位置判定，尚未加入競技型 FPS 的延遲補償。
